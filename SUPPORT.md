# Support

The Cian Open Protocol is an experimental public developer preview.

- Usage questions and reproducible defects: open a GitHub issue using the appropriate template.
- Protocol changes: open a protocol proposal before implementation.
- Security vulnerabilities: follow `SECURITY.md`; do not disclose them in a public issue.
- Commercial support, uptime and production response: not currently offered.

Do not include API keys, database URLs, private keys, real conversation content
or private Welsh-review records in issues or logs.
