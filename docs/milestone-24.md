# Milestone 24 — independent-assessment evidence packs

Milestone 24 prepares coherent evidence for three independent workstreams:

- external security assessment;
- production signing-key custody; and
- UK/Wales privacy and legal review.

The pack includes a reviewer index, security control/evidence matrix, open key-custody decision record, factual privacy data inventory and neutral machine-readable sign-off template/schema.

Run:

```powershell
npm run assurance:check
```

A successful preparation check prints `MILESTONE_24_PACK_READY`. This means the documents are present and internally honest. It deliberately confirms that all three external gates remain blocked. Only qualified independent reviewers can produce the evidence needed to close them.
