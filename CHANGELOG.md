# Changelog

This file summarises developer-preview changes. Git history and milestone notes
contain the detailed evidence.

## 0.1.0-alpha.27

- Added contributor, support and community-conduct policies.
- Added structured bug, protocol-proposal and pull-request templates.
- Added compatibility/versioning and five-minute preview guides.
- Added a read-only release-candidate workflow with an explicit no-publication check.

## 0.1.0-alpha.26

- Prepared independent security, key-custody and privacy/legal evidence packs.
- Kept all external approval gates blocked pending signed independent evidence.

## 0.1.0-alpha.19 to alpha.25

- Added the signed To Bach ledger, durable compute pool, restart persistence,
  multi-provider matching, outside-provider onboarding, monitoring, suspension,
  token rotation, rate limiting and abuse tests.

Earlier experimental milestones are documented under `docs/milestone-*.md`.
