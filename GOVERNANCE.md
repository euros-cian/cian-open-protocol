# Governance

Cian AI Ltd is the initial steward of the v0.x specification and reference
implementation. Decisions are made in public issues and pull requests.

The universal core and each language profile are versioned independently. A
language community owns the linguistic policy of its profile; changing a profile
does not silently change the core settlement rules.

During v0.x, maintainers may reject changes that weaken backing, proof uniqueness,
independent validation, atomic settlement, machine-only holding or irreversible
retirement. Material changes require a written proposal and a review period.

The intended direction is broader technical, language-community, provider and user
representation before a stable 1.0 release.
